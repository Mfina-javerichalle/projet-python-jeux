## Snake — Serpen.py

**Langage :** Python  
**Bibliothèque :** Pygame

Jeu Snake classique revisité avec des fonctionnalités avancées.

**Fonctionnalités :**
- Niveaux progressifs avec augmentation de la vitesse
- Obstacles fixes générés aléatoirement
- Mode invincibilité temporaire
- Système de score en temps réel
- Écran de game over et relance de partie

**Lancement :**
```bash
pip install pygame
python Serpen.py
```

## Quiz Architecture Informatique — custom_final.py

**Langage :** Python  
**Bibliothèque :** CustomTkinter

Quiz interactif sur les composants et l'architecture des ordinateurs, avec interface graphique moderne en mode sombre.

**Fonctionnalités :**
- Questions à choix multiples (QCM)
- Interface graphique moderne avec thème sombre
- Score affiché en fin de partie
- Questions mélangées aléatoirement

**Lancement :**
```bash
pip install customtkinter
python custom_final.py
```

## Vrai ou Faux — vrai-ou-faux-gemini.py

**Langage :** Python  
**Bibliothèque :** Tkinter

Jeu de questions Vrai/Faux avec interface graphique et système de score.

**Fonctionnalités :**
- Interface graphique avec Tkinter
- Système de score par joueur
- Saisie du nom du joueur
- Questions variées sur la culture générale

**Lancement :**
```bash
python vrai-ou-faux-gemini.py
```
> Tkinter est inclus nativement avec Python, aucune installation supplémentaire requise.
